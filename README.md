# Smart Sun Frontend
https://smartsun-nd8o.onrender.com

Este é o frontend do projeto Smart Sun, uma aplicação web desenvolvida em React para auxiliar usuários no cálculo, consulta e acompanhamento de sistemas de energia solar. O sistema permite que o usuário cadastre-se, faça login, recupere senha por e-mail, realize simulações de economia com energia solar com base no consumo e tarifa, e visualize resultados detalhados com gráficos, incluindo impacto ambiental e retorno do investimento. Também é possível consultar o histórico de simulações realizadas, tudo por meio de uma interface moderna e responsiva.

O projeto foi desenvolvido para fins estudantis e apresentado no dia 05/06/2025 na Fundação Hermínio Ometto.

## Estrutura

- `src/`: Código-fonte React (componentes, páginas, serviços)
- `public/`: Arquivos estáticos e imagens
- `package.json`: Dependências e scripts do projeto

## Pré-requisitos

- NodeJS instalado ([download aqui]([https://nodejs.org/en/download))

## Instalação

1. Instale as dependências:
   ```
   npm install (certifique-se que o Node.js está instalado antes com node --version)
   ```

2. Inicie o projeto:
   ```
   npm start
   ```

A aplicação está disponível em [http://localhost:3000](http://localhost:3000).
